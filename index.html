Temen (Sumerian 𒋼, Akkadian temennu) is the Babylonian word for a building's foundation: the levelled platform and the pegs that fixed its outline on the ground before the first brick was laid. A few measured points, and everything else is built out from them.

          
That is what a TemenCAD script is.

Code first, by design

            
Primitives, 2D sketches with fillets and offsets, extrude, revolve, loft, roof, booleans, hulls, arrays and metric screw cutters. Plain JavaScript, with autocomplete and errors marked on the line.

          

          

            
◈

            
Always watertight

            
Built on the Manifold kernel compiled to WebAssembly. Booleans are exact and fast, and every mesh you export is a closed solid your slicer will accept.

          

          

            
✦

            
An assistant that edits the script

            
Describe a change in plain English. The assistant edits your files, builds them, reads the same errors you see and takes a screenshot to check. Your own API key, nothing proxied.

          

          

            
⇄

            
Projects and imports

            
Split a design into modules with ordinary import and export. Bring in fonts and STL meshes the same way. Save it all as one .temen file.

          

          

            
▣

            
Print-ready output

            
Pick your printer's plate and see at once whether the part fits. Export binary STL, or a 3MF with each part named and coloured for multi-material slicers.

          

          

            
>_

            
Headless, too

            
The same engine runs in Node. npx temencad model.js builds a script or a .temen project to STL or 3MF in CI, with the plate check as an exit code.

          

        

      


      

        

          
A small API that reads like the part

          
Units are millimetres, Y is up, the build plate is y = 0. Every operation returns a new shape, nothing is mutated, and anything you return or show() becomes a named part.

          Read the API reference
        


// a lid that fits the box it came from
const body = roundedBox(60, 25, 40, 3, { edges: 'vertical' }).onPlate()
  .subtract(roundedBox(56, 25, 36, 1).onPlate().translate(0, 2, 0));
const lid = projection(body).extrude(2)
  .add(projection(body, { cut: 10 }).offset(-0.25).extrude(3).translate(0, 2, 0));
return { body, lid: lid.translate(0, 0, 50) };
